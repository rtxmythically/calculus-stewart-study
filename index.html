第 01 課 / 小節 01

函數是一條規則，f(x) 是輸出

把函數想成一台有使用範圍的機器：先確認 x 能不能輸入，再按規則得到 y。f 是規則的名字，f(x) 是這次的輸出；f(3) 不是 f 乘 3。公式、表格、圖形和文字都能描述同一條規則。

「唯一」限制的是同一輸入的輸出數量。不同輸入可以得到同一輸出，例如 x² 把 2 和 −2 都送到 4，仍是函數。解題時先用一句話說規則，再把整個輸入用括號代入。

本課示範 · 自編

設 f(x)=2x²−3，求 f(−2) 與 f(a+1)。

  1. 先把規則讀成「輸入平方，乘 2，再減 3」。
  2. f(−2)=2(−2)²−3=5；括號保護整個負數。
  3. f(a+1)=2(a+1)²−3=2a²+4a−1；平方作用在整個 a+1。
  4. 圖上的點是 (輸入,輸出)，因此 (−2,5) 在圖上。下方互動另用 y=x²，觀察輸入與點座標的關係。

第 01 課 / 小節 02

公式算得出來之前，先列定義域

定義域（domain）是所有允許輸入的集合；值域（range）是實際能得到的輸出集合。沒有額外指定時，這裡以能讓公式產生實數的輸入為自然定義域。

分母不能為 0；偶次根號內必須 ≥0；對數真數必須 >0。多個限制要同時成立，所以取交集。區間 [a,b] 包含端點，(a,b) 不包含；∞ 不是實數端點，永遠用小括號。

本課示範 · 自編

比較 F(x)=(x²−4)/(x−2) 與 G(x)=x+2，並求 H(x)=√(x+3)/(x−1) 的定義域。

  1. F 可以在 x≠2 時約成 x+2，但原分母已排除 x=2。
  2. G 在所有實數都有定義，G(2)=4；所以 F 與 G 不是同一函數，雖然在共同定義域的輸出相同。
  3. H 的根號要求 x≥−3，分母要求 x≠1，兩條同時保留。
  4. 因此 H 的定義域為 [−3,1)∪(1,∞)。若根號包住整個分式，條件將改成一個分式不等式，不能沿用本答案。

換你一步 · 先自己想

化簡 x(x−5)/(x−5) 後，還要留下哪個限制？

仍須留下 x≠5。約分改變寫法，不能把原本禁止的輸入補回去。

容易卡住：「代入得到 0」和「分母得到 0」不同：輸出 0 可以合法，除以 0 不合法。

第 01 課 / 小節 03

讀圖與判斷函數：固定 x，再看 y

座標 (x,y) 就是一組輸入與輸出。判斷圖形是否表示 y=f(x)，想像一條垂直線固定一個 x：若與圖形交於兩個不同高度，同一輸入有兩個輸出，便不符合函數定義。

圖形在 x 軸的投影給定義域，在 y 軸的投影給值域；空心點不包含，實心點包含。水平線測試則是在問一對一，和垂直線測試的用途不同。

本課示範 · 自編

關係 y²=x+1 與函數 y=√(x+1) 有什麼不同？

  1. 在第一個關係取 x=3，會得到 y=2 或 y=−2。
  2. 垂直線 x=3 交到兩點，因此完整的關係不能把 y 定義成 x 的函數。
  3. 第二個公式的 √ 指非負平方根，只取 y≥0 的上半支。
  4. 其定義域是 [−1,∞)，值域是 [0,∞)；限制哪一支，會影響是否為函數。

換你一步 · 先自己想

y=x² 通過垂直線測試，是否也一定通過水平線測試？

不一定。它是函數，但 y=4 同時對應 x=2、−2，所以在全實數上不是一對一。

容易卡住：不能因為圖形有兩個 x 對應同一 y，就判定它不是函數；應固定 x 檢查。

第 01 課 / 小節 04

圖形變換與複合：先分清內外層

f(x)+k 改輸出，整張圖上下移 k；f(x−h) 改輸入，原先在輸入 0 的特徵會出現在 x=h，因此向右移 h。−f(x) 對 x 軸反射，f(−x) 對 y 軸反射；af(x) 把高度乘 a。

f(g(x)) 是先做 g，再把結果交給 f。合法輸入要同時讓 g(x) 存在，且讓 g(x) 落在 f 的定義域。把式子代進去後，還要再檢查限制；複合一般不能交換順序。

本課示範 · 自編

由 y=x² 讀出 y=−2(x−4)²+3 的圖形，再比較 √(x−4) 與 √x−4。

  1. 先找 x−4=0 的位置：頂點移到 x=4。
  2. 外面的 −2 讓圖上下反射且高度乘 2，最後上移 3，頂點為 (4,3)，值域 (−∞,3]。
  3. 若 f(t)=√t、g(x)=x−4，則 f(g(x))=√(x−4)，定義域 x≥4。
  4. g(f(x))=√x−4，定義域 x≥0。括號位置同時改變圖形和合法輸入。

換你一步 · 先自己想

y=f(x+2)−1 將原圖往哪兩個方向移動？

向左 2、向下 1。內層 x+2=0 出現在 x=−2，外層減 1 則降低高度。

容易卡住：水平變換看「讓內層回到原輸入的 x 是多少」，不要只照括號內正負號背方向。

判斷輸入是否決定唯一輸出

先補這個方法：讀圖與判斷函數：固定 x，再看 y

方程式 3x − 5y = 7 是否將 y 定義為 x 的函數？

此處只保存作答文字，不會自動批改。

先把 y 單獨留在等號一邊，再檢查一個 x 會得到幾個 y。

一步一步解
  1. 移項得 −5y = 7 − 3x。
  2. 除以 −5 得 y = (3x − 7)/5。
  3. 每個實數 x 都恰好產生一個 y，因此符合函數的定義。

同一輸入能否產生兩個輸出

先補這個方法：讀圖與判斷函數：固定 x，再看 y

試著固定 x = 0，看看 y 的可能值。

一步一步解
  1. 令 x = 0，得到 (y − 3)² = 5。
  2. 因此 y = 3 + √5 或 y = 3 − √5。

式子相同，函數就相同嗎

先補這個方法：公式算得出來之前，先列定義域

若 f(x) = (x² − x)/(x − 1)，而 g(x) = x，是否 f = g？

此處只保存作答文字，不會自動批改。

約分之前，先記下原分母不能等於 0。

一步一步解
  1. 原式要求 x ≠ 1；在此條件下 f(x) = x(x − 1)/(x − 1) = x。
  2. g 的定義域是所有實數，而 f 不允許輸入 1。
  3. 相同函數必須連定義域也相同；約分不會補回原本缺少的輸入。
答案：f ≠ g；它們在 x ≠ 1 時值相同，但定義域不同。

第 02 課 / 小節 01

整數次方、負次方與根號是一套延伸規則

正整數次方是重複相乘。為了讓 aᵐ/aⁿ=aᵐ⁻ⁿ 持續成立，在 a≠0 時定義 a⁰=1、a⁻ⁿ=1/aⁿ。負次方表示倒數，不表示答案變成負數。

分數次方把根號寫成指數；在正底數 a>0 上，a^(m/n)=(ⁿ√a)ᵐ。偶次根號在實數範圍只取非負主值。特別是 √(x²)=|x|，因為平方根的輸出不能為負。

本課示範 · 自編

求 16^(3/4)、2⁻³，並比較 √25 與方程式 z²=25。

  1. 16^(3/4) 先取四次根得到 2，再立方，結果是 8。
  2. 2⁻³=1/2³=1/8；指數負號移動的是分子、分母的位置。
  3. √25=5 是一個非負數；解 z²=25 則要同時保留 z=±5。
  4. 同理取 x=−3 時，√(x²)=3=|x|，不能寫成 −3。

換你一步 · 先自己想

把 x⁻² 與 √(x²) 分別改寫成不含負次方、根號的形式。

x⁻²=1/x²（x≠0）；√(x²)=|x|（所有實數 x）。兩者的限制不同。

容易卡住：aᵐ+aⁿ 不能合成 aᵐ⁺ⁿ；指數相加對應的是同底數相乘。

第 02 課 / 小節 02

指數函數把未知數放在「次數」的位置

x³ 的底數在變，是冪函數；3ˣ 的次數在變，是指數函數。對 a>0、a≠1，aˣ 的輸入可以是任意實數，輸出永遠為正。a>1 時遞增，0<a<1 時遞減，圖形都通過 (0,1)。

這種函數用來描述「每過相同時間就乘相同比例」。例如每期乘 1.1 是等比成長；每期加 1.1 是另一種線性模型。辨認式子時先找 x 所在的位置。

本課示範 · 自編

一個量的模型是 P(t)=100·2ᵗ。求 P(0)、P(−1)，並寫出 P(t+1) 與 P(t) 的關係。

  1. P(0)=100·1=100，這是模型的起始量。
  2. P(−1)=100/2=50，負的時間指數對應往前推一個倍增週期。
  3. P(t+1)=100·2ᵗ·2=2P(t)，每增加一個時間單位就乘 2。
  4. 模型適用的時間範圍仍由情境決定；公式可算所有實數，不代表現實都適用。

換你一步 · 先自己想

y=(1/3)ˣ 的 y 截距是多少？x 增加時它如何變化？

y 截距為 1；底數介於 0 與 1，所以隨 x 增加而遞減，但保持正值。

容易卡住：aˣ 不會等於 0。求 aˣ=負數，在實數範圍沒有解。

第 02 課 / 小節 03

log 是「次方的反問」，先翻譯再計算

logₐ b=c 的完整意思是 aᶜ=b。a 是底數，b 是真數，c 是答案所代表的指數。要求 a>0、a≠1、b>0，因為指數函數的輸出只有正數，且底數 1 無法提供一對一的倒推。

所以 logₐ1=0、logₐa=1，並且 logₐ(aˣ)=x。計算精確值時，先把真數寫成底數的次方；真數小於 1 時答案可能為負，真數本身仍必須大於 0。

本課示範 · 自編

求 log₂32、log₂(1/8)、log₁₆4。

  1. 2⁵=32，所以 log₂32=5。
  2. 2⁻³=1/8，所以 log₂(1/8)=−3。
  3. 令 log₁₆4=c，翻成 16ᶜ=4；以 2 為底可寫 2^(4c)=2²。
  4. 得到 4c=2、c=1/2。每個答案都能代回次方關係檢查。

換你一步 · 先自己想

log₅(1/25)=k。先寫出不含 log 的等式，再找 k。

5ᵏ=1/25=5⁻²，所以 k=−2。

容易卡住：logₐb 不是 a×b 或 b/a；它的輸出是一個次方的次數。

第 02 課 / 小節 04

ln 是以 e 為底的 log，不是一個新運算體系

ln 的第一個字母是小寫 L，讀作自然對數（natural logarithm）。e≈2.71828 是固定常數；ln x 就是 logₑx，問「e 要升到幾次方才能得到 x？」因此 ln x=y 與 eʸ=x 完全等價。

ln 的定義域是 x>0，值域是全實數。ln1=0、ln e=1、ln(eᵗ)=t；e^(ln x)=x 要求 x>0。計算機的 ln 鍵只是幫你算這個指數，不需要先學新的乘除規則。

本課示範 · 自編

把 ln u=−2 改寫成指數式，並求 ln(e⁴)、e^(ln 7)。

  1. ln u=−2 問的是 e 的哪個次方等於 u，所以 u=e⁻²。
  2. e⁻² 是正數，符合 u>0；ln 的答案為負並不違反定義域。
  3. ln(e⁴)=4，因為 e⁴ 已經明示了所需指數。
  4. e^(ln 7)=7，因為 ln 7 正是把 e 送到 7 所需的指數。

換你一步 · 先自己想

ln x=0 時，先改寫成哪個指數式？

x=e⁰=1。先用定義，不需要計算機。

容易卡住：ln(−2) 在本課的實數範圍沒有定義；但 ln(1/2) 有定義且為負。

第 02 課 / 小節 05

反函數要先確認一對一，再交換角色

反函數把原本的輸出當成新輸入，因此原函數必須一對一：不同輸入不能擠到同一輸出。圖形用水平線測試檢查。原定義域與值域在反函數中交換。

計算流程是寫 y=f(x)、在限制下反解 x、最後把輸入名稱改回 x。平方、三角等函數常要先限制一段。f⁻¹ 是倒推規則，1/f 則是把輸出取倒數，兩者不同。

本課示範 · 自編

f(x)=(x−2)²+1，限制 x≥2。求反函數及其定義域。

  1. 因 x≥2，原圖只留右半支，遞增且一對一；原值域為 y≥1。
  2. 由 y−1=(x−2)²，且 x−2≥0，選 x−2=√(y−1)。
  3. 交換輸入輸出名稱，f⁻¹(x)=2+√(x−1)，定義域 x≥1，值域 x≥2。
  4. 檢查 f(5)=10、f⁻¹(10)=5，正向與反向應能接回去。

換你一步 · 先自己想

若只給 f(x)=x²、沒有任何限制，能直接說 f⁻¹(x)=√x 嗎？

不能。全實數上的平方不是一對一；先限制原輸入 x≥0，才得到這個反函數。

容易卡住：解平方時選正號或負號必須由原輸入限制決定，不能任選。

第 02 課 / 小節 06

解對數方程：條件、規則、反解、代回

對數把乘法變加法：ln(UV)=ln U+ln V，ln(U/V)=ln U−ln V，前提 U,V>0。對 U>0，ln(Uʳ)=r ln U。這些規則來自指數相加對應底數相乘；沒有 ln(U+V)=ln U+ln V 這條法則。

需要小數近似時可用換底 logₐb=ln b/ln a。解方程時先列原真數條件，再合併或兩邊取 exp，最後代回原式。只有原條件通過的候選值才是解。

本課示範 · 自編

解 ln(2x−1)=2，以及 e^(3x−1)=5，保留精確式。

  1. 第一式先列 2x−1>0，即 x>1/2。
  2. 用 ln 與 exp 互為反函數，得 2x−1=e²，所以 x=(e²+1)/2，確實大於 1/2。
  3. 第二式兩側皆正，可取 ln：3x−1=ln5，得到 x=(1+ln5)/3。
  4. 精確式保留 e²、ln5；若要求三位小數，最後一步才用計算機，避免中途四捨五入。

換你一步 · 先自己想

ln(x−3)+ln(x+1) 合併前，原始合法範圍是什麼？

需要 x−3>0 且 x+1>0，合起來 x>3。之後才可合成 ln[(x−3)(x+1)]。

容易卡住：只對合併後的乘積要求 >0，可能引進兩個真數都負的假解。

第 03 課 / 小節 01

弧度用弧長衡量角，不是另一個長度單位

角 θ 的弧度數定義為弧長 s 除以半徑 r：θ=s/r。因此同一個角放大到不同半徑時，比例不變。整圈弧長 2πr 對應 2π rad，也等於 360°。

度轉弧度乘 π/180；弧度轉度乘 180/π。由定義可反過來用 s=rθ 求弧長，但 θ 必須先換成弧度。微分與基本三角極限的標準公式也以弧度為前提。

本課示範 · 自編

把 150° 換成弧度，並求半徑 6 cm 時的對應弧長。

  1. 150°×π/180°=5π/6 rad；角度單位在換算中消去。
  2. 帶進 s=rθ：s=6×5π/6=5π cm。
  3. 若題目先給 3π/2 rad，換成角度就是 (3π/2)×180/π=270°。
  4. 弧長可以用半徑同樣的長度單位；θ 本身來自兩個長度之比。

換你一步 · 先自己想

半徑 4 m、角度 60°，能直接算 s=4×60 嗎？

不能。先換成 π/3 rad，再得 s=4π/3 m。

容易卡住：π rad=180°，不是 π°=180 rad；換算時保留單位能避免倒乘。

第 03 課 / 小節 02

單位圓讓 sin、cos 的正負有根據

從正 x 軸逆時針轉 θ，單位圓上的點為 (cosθ,sinθ)。cos 是水平座標，sin 是垂直座標；因此各自的值都在 [−1,1]，且 cos²θ+sin²θ=1。

tanθ=sinθ/cosθ，需要 cosθ≠0。sec、csc、cot 分別是 cos、sin、tan 的倒數（使用各自分母非零的地方）。週期表示轉一圈後重複：sin、cos 的週期為 2π，tan 為 π。

本課示範 · 自編

求 θ=2π/3 的 sin、cos、tan。

  1. 2π/3=120°，位於第二象限，參考角為 π/3。
  2. 參考角的水平、垂直長度為 1/2、√3/2；第二象限水平負、垂直正。
  3. 所以 cos(2π/3)=−1/2、sin(2π/3)=√3/2。
  4. tan 為垂直除以水平，結果 −√3；用座標判號比單背符號表可靠。

換你一步 · 先自己想

θ 在第三象限時，sinθ 與 cosθ 分別是正還是負？tanθ 呢？

sin、cos 都負，所以 tan 為正。仍須排除分母為零的位置。

容易卡住：sin²θ 表示 (sinθ)²，與 sin(θ²) 不同；括號決定運算次序。

第 03 課 / 小節 03

圖形的振幅、週期與反三角函數

y=A sin(Bx) 在 B≠0 時，振幅是 |A|，週期是 2π/|B|。輸入轉得越快，完成一圈所需的 x 區間越短。三角函數有重複輸出，因此整條圖形不能直接反解成單一值。

arcsin x（也寫 sin⁻¹x）的輸出限制在 [−π/2,π/2]；arccos x 在 [0,π]；arctan x 在 (−π/2,π/2)。arcsin、arccos 的輸入要在 [−1,1]，arctan 的輸入可為任意實數。

本課示範 · 自編

求 arcsin(−√3/2) 與 arccos(0)，並讀出 2 sin(3x) 的週期。

  1. arcsin 問 sin 哪個角等於 −√3/2，而且角必須落在 [−π/2,π/2]。
  2. 選 −π/3；雖然許多角有同樣的 sin 值，反函數只回傳主要值。
  3. arccos(0)=π/2，位於指定的 [0,π] 區間。
  4. 2 sin(3x) 的振幅為 2、週期 2π/3；外面乘 2 不改變週期。

換你一步 · 先自己想

sin⁻¹(1/2) 和 1/sin(1/2) 是同一件事嗎？

不同。前者通常指 arcsin(1/2)=π/6，後者是把 sin(1/2 rad) 的輸出取倒數。

容易卡住：反三角函數的答案是角；要先看主要值區間，不能把所有週期解都交成它的函數值。

第 04 課 / 小節 01

極限看附近，點值看當下

limₓ→ₐ f(x)=L 的意思是：輸入從定義域內靠近 a、但不等於 a 時，輸出可以任意接近 L。a 點是否有定義、定義成多少，是另一個問題。極限不是把 x「換成」a 的記號。

數值表與圖形能幫你猜趨勢，但少量樣本不能證明所有足夠靠近的輸入都符合。正式解題需要代數、極限性質或定義支持。

本課示範 · 自編

p(x)=(x²−1)/(x−1)，比較 p(1) 與 x→1 時的極限。

  1. 原式在 x=1 分母為 0，所以 p(1) 沒有定義。
  2. 對 x≠1，因式分解後 p(x)=x+1。
  3. 當 x 從左右靠近 1，x+1 都靠近 2，故極限是 2。
  4. 即使另外定義 p(1)=9，附近公式不變，極限仍是 2。下方互動把點越放越靠近 1，觀察附近輸出而非點值。

若 limₓ→₃ f(x)=8，而另定義 f(3)=0，這兩句能同時成立嗎？

可以。前者描述去心附近的趨勢，後者只指定 3 這一點的值。

第 04 課 / 小節 02

兩側極限要分別問，再比較

x→a⁻ 表示從小於 a 的左側靠近；x→a⁺ 從大於 a 的右側靠近。在 a 的兩側都有定義域點可接近的情況下，有限的兩側極限存在，等價於左右極限都存在且相等。

分段公式的等號決定點值，由哪一邊靠近則決定用哪個附近公式。若一側無界、震盪或左右趨向不同值，就不能宣稱有同一個有限兩側極限。

本課示範 · 自編

q(x)=x+2（x<1）、q(1)=6、q(x)=3x（x>1）。判斷 x→1 的極限。

  1. 從左用 x+2，得到左極限 3。
  2. 從右用 3x，得到右極限 3。
  3. 兩側一致，兩側極限為 3；q(1)=6 不參與前兩步。
  4. 若把右側公式改為 3x+1，右極限變成 4，此時兩側極限不存在。

換你一步 · 先自己想

如果左極限為 −2、右極限為 2，可以把它們平均後說極限是 0 嗎？

不可以。兩側必須趨近同一值，平均數不能補出一個不存在的極限。

容易卡住：x→a⁻ 的負號描述輸入方向，並不代表答案一定為負。

第 04 課 / 小節 03

ε–δ 定義是保證誤差的規則

ε（epsilon）是別人要求的輸出誤差：希望 |f(x)−L|<ε。δ（delta）是我們能給出的輸入距離：只要 0<|x−a|<δ，就保證輸出符合要求。先給任意 ε>0，再找 δ>0；δ 可依 ε 而定，不能依某一個特選的 x 才成立。

完整語意是對所有定義域內符合輸入限制的 x 都成立。找 δ 時可以倒推，寫證明時則從假設的輸入距離正推到輸出誤差。0< 排除了 a 點本身，正呼應「看附近」。

本課示範 · 自編

對 f(x)=3x+1，在 a=2 證明極限為 7，並在 ε=0.06 時選 δ。

  1. 先把輸出誤差整理：|f(x)−7|=|3x−6|=3|x−2|。
  2. 想讓它小於 ε，只需 |x−2|<ε/3，因此選 δ=ε/3。
  3. 正向寫：任給 ε>0，取 δ=ε/3；若 0<|x−2|<δ，則 |f(x)−7|<3δ=ε。
  4. 當 ε=0.06，可選 δ=0.02；更小的正 δ 也符合保證，不必一定找最大值。

換你一步 · 先自己想

若輸出誤差可整理成 5|x−a|，要保證它 <ε，可以選哪個 δ？

選 δ=ε/5；再從 |x−a|<δ 推到 5|x−a|<ε。

容易卡住：不要只寫出 δ 的數字；必須說明它如何保證所有足夠靠近的輸入。

先試代入，卡住後才選工具

若各部分有有限極限，加減乘的極限可逐項處理；商還要求分母極限不為 0。多項式在每個實數點可代入，有理函數則需確認分母。合法代入已得到數字時，不需要再製造複雜步驟。

若代入變成 0/0，只代表這套直接商法則不能立刻用。看到多項式差通常先因式分解；看到兩個根號相減通常用共軛；有界振盪乘上趨近 0 的量可考慮夾擠。此時還沒學微分，不用羅必達跳過代數理由。

本課示範 · 自編

比較 x→2 時 (x²+1)/(x+3) 與 (x²−4)/(x−2)。

  1. 第一式分母趨近 5≠0，可直接得到 5/5=1。
  2. 第二式直接代入為 0/0，先分解 x²−4=(x−2)(x+2)。
  3. 在去心附近 x≠2，可以約成 x+2，極限為 4。
  4. 約分只在去心附近成立，已足夠支持極限；不用把原函數在 2 補定義。

第 05 課 / 小節 02

共軛把根號差變成可約的因子

共軛利用 (A−B)(A+B)=A²−B²，把難處理的根號差變成代數差。你是在分子、分母同乘一個比值為 1 的式子，並沒有改變函數在共同定義域的值。

先寫完整相乘，再利用差平方約掉造成 0/0 的因子。最後檢查去心附近分母不為零、根號有定義，才代入。

本課示範 · 自編

求 limₕ→₀ [√(16+h)−4]/h。

  1. 代入得到 0/0；根號差提示使用 √(16+h)+4 作共軛。
  2. 同乘後分子變成 (16+h)−16=h。
  3. 對 h≠0 約掉 h，得到 1/[√(16+h)+4]。
  4. 當 h→0，分母趨近 8，極限為 1/8。h=0 附近也確實有 16+h>0。

換你一步 · 先自己想

有理化 √(9+h)−3 時，應乘哪個共軛？

乘 √(9+h)+3；若整題是分式，分子、分母必須一起乘。

容易卡住：只乘分子會改變原式；共軛的正負也不要抄成原來的根號差。

第 05 課 / 小節 03

三角極限要配出「同一個角」

在弧度制下 limᵤ→₀ sin u/u=1，因而 tan u/u 也趨近 1。幾何上的比較 sin u≤u≤tan u（小的正 u）可夾住 sin u/u，負側再利用對稱性處理。這個前提是 u→0，不是只有 x→0 就能忽略內層。

遇到 sin(ax)、tan(bx) 時，把分母配成相同角度，再把補出的常數放回式子。標準極限只替換配好的比值，不能把所有三角函數粗暴刪掉。

本課示範 · 自編

求 limₓ→₀ tan(4x)/sin(5x)。

  1. 改寫成 [tan(4x)/(4x)]·[5x/sin(5x)]·(4/5)。
  2. 4x、5x 都隨 x→0 而趨近 0，所以前兩個比值都趨近 1。
  3. 由乘法極限性質得到 1·1·4/5=4/5。
  4. 也可先拆 tan=sin/cos；cos(4x) 趨近 1，仍要保留角度倍率。

換你一步 · 先自己想

limₓ→₀ sin(7x)/x 應補出哪個常數？

寫成 [sin(7x)/(7x)]·7，因此極限為 7。

容易卡住：sin(7x)/x 不是標準比值本身；角度倍率不能漏掉，角度必須以弧度衡量。

第 05 課 / 小節 04

夾擠讓你不用追逐每一次振盪

若在 a 的去心附近 g(x)≤f(x)≤h(x)，而兩個外側函數都趨近同一個 L，中間函數也趨近 L。重點是上下界要一起縮到同一值；只有「有界」並不能推出極限存在。

cos、sin 的值都在 [−1,1]，常與趨近 0 的非負因子結合。也可改用絕對值：若 |f(x)−L|≤b(x)、b(x)→0，就能控制輸出誤差。

本課示範 · 自編

證明 limₓ→₀ x² sin(1/x)=0（在 x≠0 定義）。

  1. 因 −1≤sin(1/x)≤1，而 x²≥0，乘上後得到 −x²≤x²sin(1/x)≤x²。
  2. 兩側的 −x²、x² 都趨近 0。
  3. 依夾擠定理，中間函數的極限也為 0。
  4. sin(1/x) 自己沒有極限；成功的原因是外面的振幅 x² 把振盪壓到 0。

換你一步 · 先自己想

無窮遠看主導項，靠近零分母看符號

x→∞ 描述輸入往無窮遠移動；f(x)→∞ 描述輸出沒有上界，兩者不能混成一件事。多項式比值在無窮遠可分子、分母同除分母的最高次方，留下可判斷的 1/x 項。

本課示範 · 自編

求 (3x²−1)/(2x²+5x) 在 x→∞ 的極限，並比較 1/(x−1) 在 1 的左右極限。

  1. 第一式同除 x²，得到 (3−1/x²)/(2+5/x)，極限為 3/2。
  2. 對 1/(x−1)，從右靠近時分母為很小的正數，輸出→+∞。
  3. 從左靠近分母為很小的負數，輸出→−∞；所以沒有同一個兩側極限。
  4. ∞ 是無界趨勢，不能當實數直接代入。另如 √(x²)/x=|x|/x，在 +∞ 為 1，在 −∞ 為 −1。

x→∞ 時 (2x+1)/(x²+3) 趨近多少？先比較哪個結構？

連續是三個條件一起成立

f 在 a 連續，要求 f(a) 有定義、limₓ→ₐf(x) 存在，且兩者相等。可簡記成 limₓ→ₐf(x)=f(a)，但做證明時要知道等號兩側為什麼有意義。

多項式、指數與三角等基本函數在各自定義域上連續；有理式在分母非零處連續。連續函數的和、積、合法商及合法複合仍連續，使用時要寫出限制。

本課示範 · 自編

驗證 f(x)=2x²+(x−1)³ 在 x=2 連續。

  1. f(2)=2·4+1=9，點值有定義。
  2. x² 與 (x−1)³ 為多項式，可用極限的和、積性質。
  3. limₓ→₂f(x)=2·2²+(2−1)³=9。
  4. 極限等於 f(2)，因此在 2 連續；同樣理由也可證明它在所有實數處連續。

換你一步 · 先自己想

要表達 f 在 a=5 連續，最精簡的等式是什麼？

limₓ→₅ f(x)=f(5)，其中兩側都要存在且是同一個實數。

容易卡住：只說「代入可以算」不等於已證明極限等於點值，尤其遇分段函數要分開檢查。

第 06 課 / 小節 02

間斷要找原因，補點只修得了其中一種

可去間斷是附近極限存在，但點值缺少或接錯；可把點值重新定義為該極限補好。跳躍間斷的左右有限極限不同，改單點無法使它們相同。無界間斷也不能靠填一個有限點值修好。

分段題若要決定參數，先算左右極限讓它們相等，再讓包含等號的那一段給出相同點值。區間端點只檢查可由區間內靠近的單側連續。

本課示範 · 自編

f(x)=x+1（x<2）、f(2)=k、f(x)=2x−1（x>2），找使 f 在 2 連續的 k。

  1. 左極限由 x+1 得到 3，右極限由 2x−1 也得到 3。
  2. 附近極限已存在，因此最後只需令 f(2)=k=3。
  3. 若右側換成 2x，右極限變 4，便沒有任何 k 能讓兩側接起來。
  4. 像 1/(x−1) 在 x=1 附近無界，補一個 k 也不能修成連續。

換你一步 · 先自己想

若左右極限都等於 7，但點值未定義，應怎樣補點才能連續？

定義 f(a)=7。要補的是點值，不必修改附近的函數。

容易卡住：分母為零要看整個式子能否消因子及極限；不能一概說全部都是同一種間斷。

第 06 課 / 小節 03

中間值定理保證存在，沒有直接給出位置

若 f 在閉區間 [a,b] 連續，則介於 f(a)、f(b) 之間的每個數值都會在某處被取到。特別是端點異號，就至少有一個零點。這是連續性把兩端接起來的結果。

它只保證至少一個，不保證唯一，也不直接算出零點。若想證明唯一，還要加入單調性等理由。對有垂直漸近線的區間，不能只看端點異號就用這個定理。

本課示範 · 自編

證明 x³+x−1=0 在 (0,1) 至少有一個實數解。

  1. 令 f(x)=x³+x−1；它是多項式，所以在 [0,1] 連續。
  2. f(0)=−1、f(1)=1，0 介於兩端輸出之間。
  3. 由中間值定理，存在 c∈(0,1)，使 f(c)=0。
  4. 目前已完成「存在」的要求；若再學導數，可利用 f′=3x²+1>0 進一步證明唯一。

換你一步 · 先自己想

1/x 在 [−1,1] 的端點異號，能因此保證區間內有零點嗎？

不能。它在 0 沒有定義，缺少整個閉區間連續的條件，不能使用中間值定理。

容易卡住：定理的條件是推理的一部分，不能把「看起來會穿過」代替連續性的檢查。

第 07 課 / 小節 01

差商先量平均，再把區間縮短

兩點間的平均變化率是輸出差除以輸入差。固定起點 a、另一點在 a+h，割線斜率為 [f(a+h)−f(a)]/h，其中 h≠0。若 h 從兩側靠近 0 時有同一個有限極限，這個數就是導數 f′(a)。

導數的單位是「輸出單位／輸入單位」；位置對時間的導數是速度，成本對產量的導數是邊際成本。h 可以正也可以負，因為瞬間的定義要比較兩側。

本課示範 · 自編

用定義求 f(x)=x² 在 a 點的導數。

  1. 先完整展開 f(a+h)=(a+h)²=a²+2ah+h²。
  2. 差商為 [(a²+2ah+h²)−a²]/h=2a+h，這一步要求 h≠0。
  3. 令 h→0 得 f′(a)=2a；若 a=1，切線斜率為 2。
  4. 下方互動固定 a=1，割線斜率為 2+h；h 越靠近 0，割線越靠近同一條切線。

換你一步 · 先自己想

若 f(x)=3x²，差商約掉 h 後是 6a+3h，f′(a) 是多少？

取 h→0，得到 f′(a)=6a。不要在約掉 h 以前把 h 直接設為 0。

容易卡住：f(a+h)−f(a) 要把 f(a) 整體放進括號相減；漏括號容易把常數符號抄反。

第 07 課 / 小節 02

由導數走到切線方程與速度

f′(a) 是在指定輸入 a 的一個斜率；讓 a 改成任意 x，就得到導函數 f′(x)。導數本身不等於切線方程，還要搭配原曲線上的點 (a,f(a))。點斜式是 y−f(a)=f′(a)(x−a)。

若 s(t) 是位置，v(t)=s′(t)；速度的正負指移動方向，速率則是 |v(t)|。題目要在 t=a 求速度，就先求一般導函數，再代 a，並寫上單位。

本課示範 · 自編

對 f(x)=x²+2，在 x=2 找切線；再求 s(t)=t⁻¹ 在 t=2 的速度。

  1. f(2)=6，f′(x)=2x，所以 f′(2)=4。
  2. 切線通過 (2,6)，方程 y−6=4(x−2)，即 y=4x−2。
  3. 位置函數 s(t)=1/t 的差商或之後的冪次法則給 s′(t)=−1/t²。
  4. 在 t=2，速度為 −1/4；若位置以 m、時間以 s，單位為 m/s，負號表示往負方向。

換你一步 · 先自己想

曲線在 (1,4) 的導數是 −3，切線應如何列式？

y−4=−3(x−1)。先把點與斜率各放到正確位置，不要把導數本身當成整條直線。

容易卡住：切線點的高度要代原函數 f；斜率才代 f′。

第 07 課 / 小節 03

位置函數沒有現成公式時，就回到差商

瞬時速度的定義與導數相同：v(a)=limₕ→₀[s(a+h)−s(a)]/h。此時 a 是指定的時刻，h 是靠近它的時間差，兩個角色要分開。代入位置函數後，先通分、整理分子，再約 h。

分式位置函數常在 t=0 不合法；若模型只討論 t>0，取 a>0 並把 h 限在 a 附近即可。求得一般 v(a) 後，才能依題目需要代不同時刻，避免同一套代數重複做。

本課示範 · 自編

s(t)=2/t² 公尺（t>0），用定義求一般瞬時速度，並求 t=2 時的值。

  1. 差商為 [2/(a+h)²−2/a²]/h，其中 a>0、h≠0，且 a+h>0。
  2. 通分後分子為 2[a²−(a+h)²]=−4ah−2h²。
  3. 約掉 h，得 (−4a−2h)/[a²(a+h)²]；h→0 後 v(a)=−4/a³。
  4. v(2)=−1/2 m/s，表示往負方向移動；速率為 1/2 m/s。後面學到冪次法則，可用它快速核對。

換你一步 · 先自己想

差商通分後若分子含 h，而分母還有整個 h，應先做哪一步？

先在 h≠0 的去心範圍約掉共同因子，再取 h→0；不能先把 h 設成 0。

容易卡住：a 點的位置值與 a 時刻的速度是不同量，答案要用正確單位。

第 07 課 / 小節 04

連續是可微的必要條件，但還不夠

若 f 在 a 可微，則 f 在 a 連續：可把 f(a+h)−f(a) 寫成差商乘 h，有限的導數乘趨近 0 的 h，使輸出差也趨近 0。反過來，連續函數仍可能有尖角、尖點或垂直切線，而沒有有限導數。

分段函數的可微問題要先檢查連續，再比較左右差商。左右斜率不同時，改一個點值不能消除尖角。圖上的垂直切線可能有無界斜率，但不符合這裡有限導數的定義。

本課示範 · 自編

檢查 f(x)=|x| 在 x=0 是否可微。

  1. f 在 0 的點值為 0，左右輸出都趨近 0，所以連續。
  2. h>0 時差商 |h|/h=1，右導數為 1。
  3. h<0 時差商 |h|/h=−1，左導數為 −1。
  4. 兩側不一致，所以在 0 不可微；這個例子說明連續不能直接推出可微。

換你一步 · 先自己想

若某函數在 a 跳躍不連續，還有必要計算它是否在 a 可微嗎？

不必。可微必連續，因此不連續已足以否定可微。

容易卡住：不是每個看起來相接的圖形都能畫出唯一的有限斜率；尖角要算兩側差商。

第 08 課 / 小節 01

常數、冪次與線性組合先分開

導數是變化率，所以固定常數的導數為 0；x 的導數為 1。在原函數有定義且可微的位置，冪次法則給 (xʳ)′=r xʳ⁻¹；任意實數 r 先在 x>0 使用，其他位置另檢查根號與分母。

線性法則允許常數提出、加減逐項微分。這只適用加減結構，並沒有把乘積拆成「導數相乘」的權利。根號、負次方可以先改成冪次，讓同一套法則適用。

本課示範 · 自編

求 f(x)=4x⁵−3√x+2/x 在 x>0 的導數。

  1. 先改寫成 4x⁵−3x^(1/2)+2x⁻¹。
  2. 逐項使用係數乘冪次法則：20x⁴−(3/2)x^(−1/2)−2x⁻²。
  3. 改回熟悉寫法：f′(x)=20x⁴−3/(2√x)−2/x²。
  4. 原式已因 1/x 排除 0；導數中的根號分母也要求本題 x>0。

換你一步 · 先自己想

常數 7、函數 7x、函數 x⁷ 的導數各是什麼？

依序為 0、7、7x⁶。先看 7 是固定輸出、係數，還是指數。

容易卡住：導數不是把每一個 x 都刪掉；指數要乘到前面，原指數再減 1。

第 08 課 / 小節 02

乘積法則：一邊改變時，另一邊還在

當 u、v 都隨 x 改變，uv 的變化包含 u 改變帶來的部分和 v 改變帶來的部分。因此 (uv)′=u′v+uv′，不是 u′v′。把兩個因子先各取一個簡單名字，能避免漏項。

可先展開的多項式乘積，也能先展開再逐項微分；兩條路應給同一結果。若乘積包含指數、三角等不便展開的函數，乘積法則更直接。

本課示範 · 自編

求 y=(x²+2)(3x−1) 的導數。

  1. 設 u=x²+2、v=3x−1，得到 u′=2x、v′=3。
  2. 套公式 y′=2x(3x−1)+(x²+2)·3。
  3. 化簡得 y′=9x²−2x+6。
  4. 核對：先展開原式為 3x³−x²+6x−2，再微分，得到相同結果。

換你一步 · 先自己想

若 u=x、v=sin x，(uv)′ 要保留哪兩項？

保留 1·sin x 與 x·cos x，結果 sin x+x cos x。

容易卡住：兩個因子都含 x 時，不能把其中一個當常數提出。

第 08 課 / 小節 03

商法則：整個分母要平方

對可微的 u、v，且 v≠0，(u/v)′=(u′v−uv′)/v²。分子的次序可讀成「上微下不微，減上不微下微」；寫完再加括號保護整個差。

也可先化簡，或把分母改成負次方再用乘積與鏈鎖律。重點不是背唯一寫法，而是確認分母非零、減號與平方沒有遺失。

本課示範 · 自編

求 h(t)=(2t+1)/(t−3) 的導數。

  1. u=2t+1、v=t−3，u′=2、v′=1，原定義域 t≠3。
  2. h′(t)=[2(t−3)−(2t+1)·1]/(t−3)²。
  3. 分子展開為 2t−6−2t−1=−7。
  4. 得到 h′(t)=−7/(t−3)²，並保留 t≠3。

換你一步 · 先自己想

微分 (x+2)/(2x−1) 時，分子第二項應寫成什麼？

應是 −(x+2)·2；分母的導數是 2，且整項前面有商法則的減號。

容易卡住：u′/v′ 不是商的導數；v² 是原分母的平方，不是分母導數的平方。

第 08 課 / 小節 04

鏈鎖律：先外層，再乘內層的變化率

若 y=f(u)、u=g(x)，x 先改變 u，u 再改變 y。兩段變化率相乘：dy/dx=(dy/du)(du/dx)，即 (f(g(x)))′=f′(g(x))g′(x)。

先說出最外層在做什麼，再把內層完整保留到外層導數裡。若有三層就依序乘三段變化率。加減、乘積或商在最外層時，先用相應法則，再對其中的複合因子使用鏈鎖律。

本課示範 · 自編

求 y=(2−x³)⁴ 與 z=sin(3x²) 的導數。

  1. 第一式內層 u=2−x³、外層 u⁴；外層導數是 4u³。
  2. 再乘內層 u′=−3x²，得 y′=−12x²(2−x³)³。
  3. 第二式先對 sin 得 cos，內層 3x² 留在括號內。
  4. 再乘 (3x²)′=6x，得 z′=6x cos(3x²)。

換你一步 · 先自己想

y=(x²+1)⁵ 的導數中，除了 5(x²+1)⁴ 還缺什麼？

還缺內層導數 2x，所以完整為 10x(x²+1)⁴。

容易卡住：先微外層不代表把內層也改成導數放進括號；原內層要保留，內層導數另乘。

第 08 課 / 小節 05

三角、指數、對數：先有基本表，再套內層

弧度制下，(sin x)′=cos x、(cos x)′=−sin x、(tan x)′=sec²x；另外 (cot x)′=−csc²x、(sec x)′=sec x tan x、(csc x)′=−csc x cot x，各限原函數有定義的區間。

指數與對數有 (eˣ)′=eˣ、(aˣ)′=aˣ ln a、(ln x)′=1/x、(logₐx)′=1/(x ln a)，a>0、a≠1，對數另要求 x>0。看到 ln u、eᵘ 或 sin u，還要乘 u′；(ln|u|)′=u′/u 適用 u≠0 的區間。

本課示範 · 自編

求 y=e^(x²)·cos x 與 g(t)=ln(5+t²) 的導數。

  1. 第一式最外層是乘積：先取 (e^(x²))′ cos x+e^(x²)(cos x)′。
  2. 鏈鎖律給 (e^(x²))′=2x e^(x²)，所以 y′=e^(x²)(2x cos x−sin x)。
  3. 第二式最外層是 ln，內層為 5+t²，故 g′(t)=2t/(5+t²)。
  4. 因 5+t²>0，g 對所有實數 t 都有定義；若真數換成 5−t²，必須先限制 |t|<√5。

換你一步 · 先自己想

y=ln(2x+3) 的導數與原定義域各是什麼？

y′=2/(2x+3)，原定義域 x>−3/2。導數公式能寫出來，不代表可以略過原真數條件。

容易卡住：(ln u)′ 是 u′/u，不是 ln(u′)；(eᵘ)′ 也不能漏掉 u′。

第 08 課 / 小節 06

隱函數微分：y 也正在隨 x 改變

x、y 的關係未解成 y=f(x) 時，可在能局部把 y 看成 y(x) 的位置，對等式兩邊微分。x 的導數是 1，但 y 的導數是 y′，因此 (y²)′=2yy′。

含 xy 的項要用乘積法則，(xy)′=y+xy′。微分後把含 y′ 的項移到同一側，提出 y′ 再除；最後除掉的係數若為零，需要另討論該點，不能硬套最後分式。

本課示範 · 自編

由 x²+xy+y²=7 求 y′。

  1. 兩邊對 x 微分：2x+(y+xy′)+2yy′=0。
  2. 把含 y′ 的項集中：xy′+2yy′=−2x−y。
  3. 提出 y′ 得 (x+2y)y′=−(2x+y)。
  4. 在 x+2y≠0 的位置，y′=−(2x+y)/(x+2y)。若另給點座標，先確認點確實在原曲線，再代入。

換你一步 · 先自己想

對 x 微分 y³ 與 4xy，各得到什麼？

依序為 3y²y′、4y+4xy′。前者是鏈鎖律，後者再用乘積法則。

容易卡住：不能把 y 當作固定常數而微成 0，也不能把 xy 的導數只寫成 xy′。

第 08 課 / 小節 07

反函數、反三角與對數微分

若 y=f⁻¹(x)，則 f(y)=x。鏈鎖律給 f′(y)y′=1；當 f′(y)≠0 且局部反函數符合可微條件時，(f⁻¹)′(x)=1/f′(f⁻¹(x))。這讓你不用先解出整個反函數。

主要值區間使反三角公式有固定符號：(arcsin x)′=1/√(1−x²)、(arccos x)′=−1/√(1−x²)（|x|<1）；(arctan x)′=1/(1+x²)。若指數本身也含 x，例如 xˣ，先取 ln，把乘方變成乘積再微分。

本課示範 · 自編

求 y=arcsin(2x) 的導數，並示範 y=xˣ（x>0）的對數微分。

  1. 第一式用反三角基本公式再乘內層 2，得 y′=2/√(1−4x²)，可微區間為 |x|<1/2。
  2. arcsin(2x) 本身可在端點 x=±1/2 定義，但這個有限導數公式不適用端點。
  3. 對 xˣ，先寫 ln y=x ln x。對 x 微分得 y′/y=ln x+1。
  4. 乘回 y=xˣ，得 y′=xˣ(ln x+1)。不能把變動的指數當成常數套冪次法則。

換你一步 · 先自己想

已知 f(2)=5、f′(2)=3，並確定局部反函數可微，(f⁻¹)′(5) 是多少？

f⁻¹(5)=2，因此導數為 1/f′(2)=1/3；不是直接算 1/f′(5)。

容易卡住：arcsin x 與 1/sin x 的導數完全不同；先確認符號代表反函數或倒數。

第 09 課 / 小節 01

運動先看方向，再累計路程

位置 s(t) 的導數 v(t) 是速度，v′(t)=a(t) 是加速度。速度正負描述方向；速率是 |v|。v 與 a 同號時速率增加，異號時減少，因此「加速度為正」不一定表示正在加速。

位移是 s(b)−s(a)；總路程則每段移動距離都算正。先找區間內 v=0 或速度不存在的分界，確認方向是否改變，再逐段取位置差的絕對值。

本課示範 · 自編

s(t)=(t−2)²，0≤t≤3，求位移與總路程。

  1. v(t)=2(t−2)，在 2 前為負、2 後為正，因此 t=2 改變方向。
  2. s(0)=4、s(2)=0、s(3)=1。
  3. 位移為 s(3)−s(0)=−3。
  4. 路程為 |0−4|+|1−0|=5；方向被分開後，不能再用正負互相抵消。

換你一步 · 先自己想

某瞬間 v<0、a>0，物體是往哪裡移動，速率如何變化？

往負方向移動；速度與加速度異號，因此速率正在減少。

容易卡住：路程、位移、速度、速率是四個不同量；先寫題目要哪一個。

第 09 課 / 小節 03

極值先找候選點，再用符號或比較證明

臨界數是定義域內 f′=0 或 f′不存在的輸入。它只是可能出現局部極值的位置；例如 x³ 在 0 的導數為 0，卻沒有極值。若 f 在閉區間連續，絕對最大最小值可比較所有內部臨界點與兩端點。

在可微區間，f′>0 表示遞增、f′<0 表示遞減。導數由正變負得到局部極大，由負變正得到局部極小。題目要「值」就報 f(c)，要「位置」就報 c，通常兩者一起寫最清楚。

本課示範 · 自編

求 f(x)=x³−3x 在 [−2,2] 的絕對最大值與最小值。

  1. f′=3(x²−1)，內部臨界數為 x=−1、1。
  2. 連同端點計算：f(−2)=−2、f(−1)=2、f(1)=−2、f(2)=2。
  3. 因此最大值 2 在 x=−1、2 取得；最小值 −2 在 x=−2、1 取得。
  4. 若只做導數等於 0，便會漏掉端點也能取到同樣極值。

換你一步 · 先自己想

閉區間極值題求出 f′(c)=0 後，還必須比較哪些地方？

比較區間內所有臨界點（含導數不存在但函數有定義處）及兩端點的函數值。

容易卡住：不在原定義域內的點不能列為臨界數；端點也不能因為不滿足 f′=0 就刪掉。

第 09 課 / 小節 04

羅爾與平均值定理：先完整檢查三種區間

平均值定理要求 f 在 [a,b] 連續、在 (a,b) 可微，便存在 c∈(a,b) 使 f′(c)=[f(b)−f(a)]/(b−a)。它把整段平均變化率，連到某一瞬間的變化率。

若再有 f(a)=f(b)，就是羅爾定理，得到某處 f′(c)=0。驗證題的書寫順序是閉區間連續、開區間可微、端點或平均斜率、最後解 c 並檢查它確實在開區間。

本課示範 · 自編

對 f(x)=(x−1)²，在 [−1,3] 驗證羅爾定理並找 c。

  1. f 是多項式，所以在 [−1,3] 連續，且在 (−1,3) 可微。
  2. f(−1)=4=f(3)，滿足端點相等條件。
  3. 求 f′(x)=2(x−1)，令 f′(c)=0 得 c=1。
  4. 1 確實落在 (−1,3)。若換成 |x| 在 [−1,1]，0 不可微，便不能用羅爾。

換你一步 · 先自己想

f(x)=x² 在 [1,2] 的平均斜率是多少？平均值定理要解哪個方程？

平均斜率為 (4−1)/(2−1)=3；解 2c=3 得 c=3/2，位於 (1,2)。

容易卡住：端點只要求連續，開區間才要求可微；定理結論的 c 不包含兩端。

第 09 課 / 小節 05

凹向與作圖：一階、二階各回答一個問題

f′ 判函數遞增遞減；f″ 判斜率正在增加或減少。在區間上 f″>0 是凹向上，f″<0 是凹向下。反曲點需要圖形在該點連續且兩側凹向改變，不是看見 f″=0 就宣告成立。

完整草圖先列定義域、截距、對稱性與漸近線，再把 f′、f″ 的分界放進符號表，最後將關鍵點座標與兩端趨勢合起來。二階導數檢驗若 f′(c)=0、f″(c)>0 得局部極小，<0 得局部極大；等於 0 時無法判定。

本課示範 · 自編

分析 f(x)=x³−6x²+9x 的增減、局部極值與反曲點。

  1. f′=3(x−1)(x−3)，符號依序為正、負、正，所以先增、再減、再增。
  2. x=1 是局部極大，f(1)=4；x=3 是局部極小，f(3)=0。
  3. f″=6x−12，在 x<2 為負、x>2 為正，凹向在 2 改變。
  4. f(2)=2，所以反曲點為 (2,2)；畫圖時把這些座標一起標出。

換你一步 · 先自己想

f(x)=x⁴ 在 0 有 f″(0)=0，0 是反曲點嗎？

不是。f″=12x² 在 0 兩側都正，凹向沒有改變；但 0 是局部與絕對最小點。

容易卡住：反曲點不是極值點的另一個名稱；極值看 f′ 的變號，凹向改變看 f″ 的符號。

第 09 課 / 小節 06

羅必達只處理符合條件的未定式

對 f/g 的 0/0 或 ∞/∞ 型，在相應去心單側區間內 f、g 可微、g′≠0，且 f′/g′ 的極限存在（可為無窮）時，可以把原極限換成導數比的極限。兩側問題要兩側條件都適用且結果一致。

這是分子分母各自微分，並非對原商使用商法則。用第二次之前，必須重新檢查仍是允許型態。0·∞、∞−∞ 或次方型要先改寫，不能直接分別微分。

本課示範 · 自編

求 limₓ→₀ (e^(3x)−1)/sin(2x)，並說明為何可以用羅必達。

  1. 代入為 0/0；分子分母在 0 附近可微，分母導數 2cos(2x) 在夠小鄰域不為 0。
  2. 導數之比為 3e^(3x)/[2cos(2x)]。
  3. 該比值的極限為 3/2，條件符合，所以原極限也是 3/2。
  4. 若遇 (1+x)^(1/x)，先令 y 為該式、取 ln y=ln(1+x)/x；求得對數極限後，最後還要取 exp 回到 y。

換你一步 · 先自己想

limₓ→₀ (1+x)/(2+x) 可以直接套羅必達嗎？

不可以用這個理由：它不是 0/0 或 ∞/∞。直接代入即得 1/2。

容易卡住：「分式很難」不是羅必達的條件；也不能把 ln y 的極限當成 y 的極限。

第 09 課 / 小節 07

最佳化的第一步是建立正確的一個變量

先說清楚要最大或最小的量，寫成目標函數，再把限制式用來消去其他變量。正值、長度、可行範圍都屬於模型的一部分。求導數只是中段，還要證明候選點給出所需極值。

在開區間或無界區間，不能只說「比較端點」；可用導數變號或兩端趨勢證明全域結論。最後把數學輸入翻回原情境的量與單位。

本課示範 · 自編

兩個正數乘積為 36，求總和最小時的兩數。

  1. 設一個數為 x>0，另一個為 36/x，目標 S(x)=x+36/x。
  2. S′=1−36/x²；令 S′=0，因 x>0 取 x=6。
  3. 在 0<x<6 時 S′<0，在 x>6 時 S′>0，總和先減後增，因此 x=6 給全域最小。
  4. 兩數為 6、6，最小總和 12。寫出變號理由，才完成最小的證明。

周長固定為 24 的長方形，設一邊 x，要先寫哪兩個式子？

限制 2x+2y=24、目標面積 A=xy；消去 y 得 A(x)=x(12−x)，且 0<x<12。

第 10 課 / 小節 01

不定積分是一整族反導數

若 F′(x)=f(x)，就稱 F 是 f 的反導數。因常數的導數為 0，F+C 都會給出相同導數，所以 ∫f(x)dx=F(x)+C。這是找函數，不是一個已經算定的面積數字。

冪次積分為 ∫xʳdx=xʳ⁺¹/(r+1)+C（r≠−1，在合法區間）；r=−1 要另用 ∫dx/x=ln|x|+C。另外 ∫eˣdx=eˣ+C、∫cos x dx=sin x+C、∫sin x dx=−cos x+C。

本課示範 · 自編

求 ∫(3x²−4x+2)dx，並以微分檢查。

  1. 逐項積分：3·x³/3−4·x²/2+2x+C。
  2. 化簡成 x³−2x²+2x+C。
  3. 對結果微分得 3x²−4x+2，回到原被積函數。
  4. 如果另給 F(0)=5，才可用條件求 C=5；沒有初始條件就保留任意常數。

換你一步 · 先自己想

∫x⁻¹dx 能把指數加 1 後除以 0 嗎？

不能。這是冪次法則的例外，應為 ln|x|+C，限不跨過 0 的區間。

容易卡住：不定積分最後要有 +C；但 C 是整族常數，不必每一項都留下不同字母。

第 10 課 / 小節 02

u 換元是把鏈鎖律反過來讀

鏈鎖律說 [F(g(x))]′=F′(g(x))g′(x)。若被積式有「一個內層，加上它的導數作因子」，可令 u=g(x)、du=g′(x)dx，把整式變成只含 u 的基本積分。

du 包含微分因子，不能只換函數而留下混合的 x、u。差一個常數可以補平，差一個變動因子則要改寫或另找方法。積完再代回原變量，並用微分驗證。

本課示範 · 自編

計算 ∫x√(x²+4)dx。

  1. 取 u=x²+4，則 du=2x dx，因此 x dx=du/2。
  2. 整式改成 (1/2)∫u^(1/2)du。
  3. 積分得 (1/3)u^(3/2)+C，再代回 (1/3)(x²+4)^(3/2)+C。
  4. 微分核對：(1/3)·(3/2)(x²+4)^(1/2)·2x=x√(x²+4)。

基本定理第一部分：累積函數的變化率就是新加入的高度

若 f 連續，令 A(x)=∫ₐˣf(t)dt，則 A′(x)=f(x)。直覺是 x 多前進一小段 h，增加的累積量約為 f(x)h；除以 h 再縮小區間，得到當下高度。t 是積分內部的暫用變量，x 才控制上限。

若上限改成 g(x)，還要用鏈鎖律：d/dx ∫ₐᵍ⁽ˣ⁾f(t)dt=f(g(x))g′(x)。若 x 在下限，先利用 ∫ₓᵃ=−∫ₐˣ 處理方向。

本課示範 · 自編

令 A(x)=∫₂ˣ3t²dt、B(x)=∫₂^(x²+1)3t²dt，求導數。

  1. A′(x)=3x²，直接把連續的被積函數取在上限 x。
  2. 也可先積出 A(x)=x³−8，再微分核對，仍為 3x²。
  3. B 的上限是 x²+1，先把 t 換成該上限，得到 3(x²+1)²。
  4. 再乘上限導數 2x，得到 B′(x)=6x(x²+1)²。

換你一步 · 先自己想

d/dx ∫₀^(2x) cos t dt，除了 cos(2x) 還要乘什麼？

還要乘上限導數 2，所以結果為 2cos(2x)。

容易卡住：對累積函數微分時，不是先對被積函數取導數；要取它在上限的值，再處理鏈鎖律。

第 11 課 / 小節 02

基本定理第二部分：反導數在兩端的差

若 f 在 [a,b] 連續，F′=f，則 ∫ₐᵇf(x)dx=F(b)−F(a)。先找到能正確微回去的 F，再把「整個上限值」減「整個下限值」。任意常數相減會消掉，因此定積分結果不加 +C。

上下限交換會換號，區間相接可以相加。若 f 跨過 0，定積分仍照正負累積；要找總面積，先在零點分段並把每段面積取正。

本課示範 · 自編

計算 ∫₋₁²(x²−1)dx。

  1. 找反導數 F=x³/3−x，微分可回到 x²−1。
  2. 上限 F(2)=8/3−2=2/3，下限 F(−1)=−1/3+1=2/3。
  3. 相減得到 0；這表示正負面積剛好抵消，並不是圖形與 x 軸間沒有區域。
  4. 若改求總面積，需在零點 x=1 分段，對負的那段取正，再相加。

換你一步 · 先自己想

若 ∫₁⁴ f(x)dx=6，則 ∫₄¹ f(x)dx 為多少？

為 −6。交換上下限改變累積方向，不需要知道 f 的公式。

容易卡住：F(b)−F(a) 的下限代入結果要整體加括號，尤其當 F(a) 自己含負號時。

第 11 課 / 小節 03

換元遇到負號、根式與對數時要檢查整條鏈

選 u 後，把 du 寫完整，將整個被積式換成 u 才積分。根號可先改成分數次方；線性分母換元後會得到 ∫du/u=ln|u|+C。若原 integrand 在某處無定義，答案只在各合法區間上作反導數。

有負號的 du 常表示內層隨 x 變小，它必須保留到最後。想檢查係數與負號，最可靠的方法是把最後結果微分一次，而不是只看形式相似。

本課示範 · 自編

計算 ∫x√(9−x²)dx 與 ∫dx/(3x−2)。

  1. 第一式設 u=9−x²、du=−2x dx，得到 −(1/2)∫u^(1/2)du。
  2. 結果 −(1/3)(9−x²)^(3/2)+C，在 |x|<3 的內部可微回原式。
  3. 第二式設 u=3x−2、dx=du/3，得到 (1/3)ln|3x−2|+C，x≠2/3。
  4. 微分第二個答案得到 (1/3)·3/(3x−2)，核對係數正確。

換你一步 · 先自己想

若 u=4−x²，du 的負號與係數是什麼？

du=−2x dx，所以 x dx=−du/2。替換時把負號一起帶走。

容易卡住：積 1/u 得 ln|u|，不是 1/ln u；也不能把原函數被排除的點補回定義域。

第 11 課 / 小節 04

定積分換元：上下限和變量必須成套

有上下限時可選兩種完整做法：一路用 u 積分，就把原本 x=a、b 換成 u=g(a)、g(b)；若不換上下限，必須先代回 x 再帶原限。不能拿 u 的反導數搭 x 的上下限。

對單調的簡單換元，次序反轉時上下限可能由大到小；保留這個方向可自動帶出負號，不要另憑直覺再補一個。

本課示範 · 自編

計算 ∫₀¹2x cos(x²)dx。

  1. 設 u=x²、du=2x dx。
  2. x=0 對應 u=0，x=1 對應 u=1，因此變成 ∫₀¹cos u du。
  3. 得到 [sin u]₀¹=sin1；此處角度是弧度。
  4. 若先算不定積分得到 sin(x²)，也可帶原 x 上下限，結果相同。

換你一步 · 先自己想

若 u=2x+1，原積分從 x=0 到 x=3，新上下限是什麼？

由 u(0)=1、u(3)=7，所以用 u 的積分時上下限為 1 到 7。

容易卡住：只有剛好數字一樣時才會看不出錯；解題時要明寫變量標籤，不能靠巧合。

容易卡住：看到積分符號不代表一定是幾何面積；先判斷被累積的是哪個量及單位。

第 12 課 / 小節 01

曲線間面積是每片的「上減下」

用垂直小片時，寬為 dx、高為上方函數減下方函數，因此 A=∫[上−下]dx。先解交點找分界，再在每段取一個點確認上下；若上下關係交換，就要分段。

若用水平小片，高低換成左右：A=∫[右−左]dy。選能減少反解或分段的方向，並不是每題都必須用 x。幾何面積應非負，可用它檢查式子方向。

本課示範 · 自編

求 y=2x 與 y=x² 圍成的面積。

  1. 交點由 2x=x² 得 x=0、2，所以範圍為 [0,2]。
  2. 在中間取 x=1，2x=2 大於 x²=1，因此上方是 2x。
  3. A=∫₀²(2x−x²)dx=[x²−x³/3]₀²=4/3。
  4. 若交換相減次序會得到負值，那是有號差，不是這題要的幾何面積。

兩曲線在區間內再交一次，能直接把同一個「上減下」公式用到底嗎？

第 12 課 / 小節 02

圓盤與圓環：切片垂直於旋轉軸

把垂直於旋轉軸的一小片旋轉，得到薄圓盤或有洞的圓環，體積小份為截面積乘厚度。截面積是 πR² 或 π(R²−r²)，其中 R、r 是從旋轉軸量到外、內邊界的距離。

外半徑與內半徑必須先分別平方再相減；不是把兩個半徑的差平方。繞水平軸常配 dx，繞垂直軸常配 dy。繞 y=c 時距離通常要寫 |f(x)−c|，先看圖才能分內外。

本課示範 · 自編

區域 0≤x≤1、0≤y≤x+2 繞 x 軸旋轉，求體積。

  1. 垂直切片繞 x 軸形成圓盤，半徑 R=x+2，內半徑為 0。
  2. V=π∫₀¹(x+2)²dx。
  3. 可展開積分或用換元：V=π[(x+2)³/3]₀¹=19π/3。
  4. 若區域改成 1≤y≤x+2，就要扣掉內洞 π·1²，使用圓環而非原圓盤式。

第 12 課 / 小節 03

圓柱殼：切片平行於旋轉軸

平行於旋轉軸的長方形薄片旋轉成薄殼：周長 2πr、高 h、厚度 Δx 或 Δy，所以 V=∫2πrh·厚度。殼的半徑仍是到旋轉軸的距離，高則是區域上下差或左右差。

如果用圓環法需要把一個 x 拆成多個反函數分支，殼法往往更直接。選方法前，先在草圖畫一片並說出旋轉後的形狀，再決定積分變量；同一問題可能有不只一種正確設式。

本課示範 · 自編

區域 0≤x≤2、0≤y≤2−x 繞 y 軸旋轉，用殼法列式求體積。

  1. 取垂直小片，它平行於 y 軸，旋轉後成為半徑 x 的殼。

第 13 課 / 小節 01

弧長累積的是斜邊，不是垂直高度

小段曲線可用線段近似；由畢氏定理，Δs≈√[(Δx)²+(Δy)²]。若 y=f(x) 在區間上夠光滑，便得到 ds=√[1+(f′(x))²]dx，弧長 L=∫ₐᵇ√[1+(f′)²]dx。

看到 y=g(x) 時先求導數，再平方、加 1、開根號，不是直接積 f。若改以 x=g(y) 表示，可用 √[1+(dx/dy)²]dy。長度單位應是一次長度。

本課示範 · 自編

用弧長公式求 y=2x+1 在 0≤x≤3 的長度。

  1. y′=2，因此 ds=√(1+4)dx=√5 dx。
  2. L=∫₀³√5 dx=3√5。
  3. 兩端點是 (0,1)、(3,7)，距離為 √[3²+6²]=3√5，與公式一致。
  4. 直線是很好的核對例子：它的弧長應該等於端點距離。

換你一步 · 先自己想

若 y′=0、區間為 [a,b] 且 a<b，弧長公式給多少？

L=∫ₐᵇ1 dx=b−a，正是水平線段的長度。

容易卡住：根號裡平方的是導數 f′，不是原函數 f；也不能把 √(1+u²) 寫成 1+u。

第 13 課 / 小節 02

曲線弧長：先化簡根式，再找換元

弧長題的難度往往在 √[1+(f′)²] 的積分。先仔細算出導數，觀察是否形成完全平方，或能由線性內層作 u 換元。√(h²)=|h|，若要去絕對值必須知道 h 在該區間的正負。

不是所有光滑函數的弧長都能用初等函數寫出；能正確列定積分已是重要的一步。遇端點導數無界時，先在內部設有限上限，再取端點極限，不能假設普通光滑公式在端點自動成立。

本課示範 · 自編

求 y=(4/3)x^(3/2) 在 [0,1] 的精確弧長。

  1. y′=2√x，平方後為 4x，因此 L=∫₀¹√(1+4x)dx。
  2. 取 u=1+4x、dx=du/4，新上下限為 1、5。
  3. L=(1/4)∫₁⁵u^(1/2)du=(1/6)[u^(3/2)]₁⁵。
  4. 答案為 (5√5−1)/6；可先看弦長作粗略檢查，曲線長不能小於端點距離。

換你一步 · 先自己想

若根號化簡成 √[(x²+1)²]，在實數範圍可以改成什麼？

改成 |x²+1|，又因 x²+1>0，所以可寫 x²+1。

容易卡住：化簡與積分是兩步；不要在還沒算清 f′ 的時候直接猜代換。

旋轉曲面累積的是圓帶：周長乘 ds

曲線小段長 ds 繞軸旋轉近似一條圓帶，面積為周長 2πr 乘斜長 ds。因此 S=∫2πr ds。繞 x 軸時 r=|y|，繞 y 軸時 r=|x|，若繞其他軸則改成到該軸的距離。

這是曲線旋轉出的側面積，不會自動包含上下兩個圓蓋，也不是填滿內部的體積。半徑的單位乘 ds 給平方長度，可拿來區分 V 的三次長度。

本課示範 · 自編

y=x+1、0≤x≤1，繞 x 軸旋轉，求旋轉側面積。

  1. y′=1，所以 ds=√2 dx。區間上 y>0，半徑 r=x+1。
  2. S=2π∫₀¹(x+1)√2 dx。
  3. 計算得 S=2π√2[x²/2+x]₀¹=3π√2。
  4. 若題目問連同端蓋的總表面積，才另加兩端圓面積；本題的旋轉曲面不含圓蓋。

換你一步 · 先自己想

把同一條 y=f(x) 分別繞 x 軸、y 軸旋轉，哪一個因子必須改變？

ds 不變，但半徑由 |f(x)| 改成 |x|。軸改變的是到軸的距離。

容易卡住：曲面公式含 √[1+(f′)²]；圓盤體積公式含 πr²，不能互相代用。

函數平均值是總累積除以區間長度

連續函數在 [a,b]（a<b）的平均值為 f_avg=(1/(b−a))∫ₐᵇf(x)dx。它是能讓長方形與原有號積分具有相同累積量的固定高度，不一定等於端點輸出的平均。

先積分算總量，再除區間長度；這與從表格計算少數樣本的算術平均不同。若題目要找「何處達到平均值」，還要再解 f(c)=f_avg，並確認 c 在指定區間。

本課示範 · 自編

求 f(x)=x² 在 [0,3] 的平均值，並找一個達到它的位置。

  1. ∫₀³x²dx=[x³/3]₀³=9。
  2. 區間長度為 3，因此平均值為 9/3=3。
  3. 求 x²=3，在 [0,3] 中取 c=√3。
  4. 端點平均 (0+9)/2=4.5 與真正平均值 3 不同。

換你一步 · 先自己想

若 ∫₂⁶f(x)dx=20，函數在 [2,6] 的平均值是多少？

區間長度為 4，所以平均值是 5，不是除以兩個端點的總和。

容易卡住：定積分是累積量，還沒除區間長度以前不能稱為函數平均值。

第 14 課 / 小節 02

功：固定的力乘距離，變動的力逐小段累積

沿運動方向的固定力 F 推動距離 d，功為 W=Fd。若力隨位置改變，一小段功為 dW=F(x)dx，總功 ∫F(x)dx。方向相反時功可能為負，需先定義座標與力的方向。

質量 kg 不是力 N；近地面重力大小為 mg，通常以 g≈9.8 m/s² 計算。彈簧力大小 kx、抽水的每層重量及搬運距離，都可能隨位置不同。

本課示範 · 自編

將 50 kg 重物垂直提高 0.8 m，需要克服重力作多少功？

  1. 取向上為正，外力緩慢提升時需克服重力，大小 mg=50×9.8=490 N。
  2. 外力所作功為 490×0.8=392 J。
  3. 若問重力所作功，方向與位移相反，則是 −392 J。
  4. 若力大小變成隨 x 改變的 20x N，就應積 ∫20x dx，不能隨便選某一個瞬間的力相乘。

換你一步 · 先自己想

彈簧常數 k=100 N/m，從自然長度拉到伸長 0.2 m，應列哪個積分？

W=∫₀^0.2 100x dx=2 J，因為所需力由 0 線性增加，不能全程當成 20 N。

容易卡住：寫出 F=mg 再計算，能避免把 50 kg 直接當成 50 N。

第 14 課 / 小節 03

水壓與作用力：深度不同就要分層

靜水表壓 p=ρgh，其中 ρ 是密度、h 是距水面的垂直深度。壓力單位為 Pa=N/m²；作用力則是壓力乘面積。水平底面深度相同，可以直接 F=pA；直立面上深度改變，要用 F=∫ρg·深度·小面積。

令 y 從水面往下量，長方形端面的水平薄條面積為寬度 w(y)dy，所以 F=ρg∫y w(y)dy。形狀不是長方形時，要先由幾何找出隨深度改變的寬度。

本課示範 · 自編

淡水中，一片寬 2 m、高 1.5 m 的直立矩形板，上緣在水面，求單側水作用力。

  1. 以 y 表示水面下深度，0≤y≤1.5，取 ρ=1000 kg/m³、g=9.8 m/s²。
  2. 小條面積 dA=2dy，壓力 p(y)=9800y。
  3. F=∫₀^1.5(9800y)·2dy=19600·(1.5²/2)=22050 N。
  4. 板底壓力為 14700 Pa，但不能拿整片面積乘底部最大壓力，因上面各層壓力較小。

換你一步 · 先自己想

水平箱底在水面下 2 m、面積 3 m²，應先算壓力還是直接把 2 當成力？

先算 p=ρg·2，再用 F=p·3。深度不是力，壓力與作用力的單位也不同。

容易卡住：這裡使用表壓，表示水造成的額外壓力；若要求絕對壓力，須按情境另計大氣壓。

第 14 課 / 小節 04

離散質心是按質量加權的平均位置

質量 mᵢ 放在 xᵢ 時，相對原點的力矩 M=Σmᵢxᵢ，總質量 m=Σmᵢ，質心 x̄=M/m。較重的物體對平均位置影響較大；不能只把座標做普通平均。

這裡的平衡模型可把共同的重力加速度消掉，所以公式以質量加權。座標可正可負，力矩的正負表示在原點的哪一側，總質量則相加為正。

本課示範 · 自編

3 kg 放在 x=−2 m，5 kg 放在 x=6 m，求總力矩與質心。

  1. 總質量為 3+5=8 kg。
  2. 力矩 M=3(−2)+5·6=24 kg·m。
  3. x̄=24/8=3 m，落在兩個質點之間，且較靠近較重的 5 kg。
  4. 若把原點改在別處，座標與力矩會改變，但實際平衡位置不會改變。

換你一步 · 先自己想

兩個相等質量放在 x=1 與 x=7，質心在哪？

因權重相等，x̄=(1+7)/2=4；只有質量相等時才可直接平均位置。

容易卡住：不要把負座標先取絕對值，那會移動物體並改變原來的平衡問題。

第 14 課 / 小節 05

連續形心：讓許多小份取代少數質點

均勻薄片在上方 y=f(x)、下方 y=g(x) 之間，面積 A=∫(f−g)dx。每條小片的水平位置為 x、垂直中心在 (f+g)/2，因此相對 y 軸的面積矩為 Mᵧ=∫x(f−g)dx，相對 x 軸為 Mₓ=(1/2)∫(f²−g²)dx。

形心 x̄=Mᵧ/A、ȳ=Mₓ/A；均勻密度在分子分母消掉，所以形心等於質心。若密度不均勻，必須改用 dm 與質量矩，不能直接套面積公式。

本課示範 · 自編

求由 y=x、y=0、x=1 圍成的均勻三角薄片形心。

  1. 0≤x≤1，上方 f=x、下方 g=0，A=∫₀¹x dx=1/2。
  2. Mᵧ=∫₀¹x·x dx=1/3，所以 x̄=(1/3)/(1/2)=2/3。
  3. Mₓ=(1/2)∫₀¹x²dx=1/6，所以 ȳ=1/3。
  4. 形心為 (2/3,1/3)，可和三角形三個頂點座標的平均核對。

換你一步 · 先自己想

要算 x̄，應使用相對哪個軸的矩？

使用相對 y 軸的矩 Mᵧ，因為到 y 軸的水平距離才是 x。

容易卡住：Mₓ、Mᵧ 的下標是旋轉參考軸，不是直接對應最後座標的字母。

從乘積法則推公式，不把 dx 丟掉

乘積微分 d(uv)=u dv+v du；移項再積分得到 ∫u dv=uv−∫v du。選 u 不是只取一個字母，而是把整個被積式分成 u 與 dv 兩部分，dv 必須連同 dx 一起分配。

理想情況是 u 微分後變簡單，而 dv 能積出 v，使新的 ∫v du 比原題容易。先看一般換元是否已經直接；只有乘積外形，並不保證一定要分部。

本課示範 · 自編

計算 ∫x e^(3x)dx。

  1. 選 u=x、du=dx，dv=e^(3x)dx、v=e^(3x)/3。
  2. 代入公式：∫x e^(3x)dx=xe^(3x)/3−(1/3)∫e^(3x)dx。
  3. 得到 xe^(3x)/3−e^(3x)/9+C。
  4. 微分核對時，第一項產生的 e^(3x)/3 會與第二項的 −e^(3x)/3 抵消，留下原來的 xe^(3x)。

換你一步 · 先自己想

若 u=x²、dv=cos(2x)dx，du、v 分別是什麼？

du=2x dx，v=sin(2x)/2。v 的 1/2 是反鏈鎖律所需的係數。

容易卡住：公式中間是減號；v 要真正積出來，不能把 dv 直接當作 v。

第 15 課 / 小節 02

對數常適合微分，單獨一項也能拆成乘積

ln x 的導數 1/x 往往比本身更容易處理，因此可把 ln x 看成 ln x·1，選 u=ln x、dv=dx。若是 xʳ ln x，常把冪次配給 dv，積成 xʳ⁺¹/(r+1)，再與 du=dx/x 合併。

這個選法以實數 ln x 的 x>0 為前提。dv 若是 x⁻¹dx，積分會再得到 ln|x|，策略需重看；選擇是為了讓下一個積分能前進，不是死背「看到 ln 就完成」。

本課示範 · 自編

計算 ∫x ln x dx，x>0。

  1. 選 u=ln x、du=dx/x，dv=x dx、v=x²/2。
  2. 公式給 (x²/2)ln x−∫(x²/2)(1/x)dx。
  3. 新的積分簡成 (1/2)∫x dx，因此結果為 (x²/2)ln x−x²/4+C。
  4. 微分時乘積項額外產生 x/2，剛好由 −x²/4 的導數抵消。

換你一步 · 先自己想

∫ln x dx 若選 u=ln x、dv=dx，新積分會是什麼？

v=x、du=dx/x，所以新積分是 ∫1 dx，結果為 x ln x−x+C。

容易卡住：ln x·1 中的 1 也是一個可積函數；不要因看起來只有一項就排除分部。

重複分部與循環：每一步都檢查是否有進展

多項式每次微分會降次，所以 x²乘指數或三角可能需要分部兩次。若處理 eˣcos x 之類的乘積，兩次後會回到原積分，可以把它當成未知數 I，移項解出，而不是無限重做。

定積分版本為 ∫ₐᵇu dv=[uv]ₐᵇ−∫ₐᵇv du；端點必須套到整個 uv。無論做幾次，都要保留每一層負號，最後微分回去驗算。

本課示範 · 自編

令 I=∫eˣcos x dx，用兩次分部解回 I。

  1. 第一次取 u=cos x、dv=eˣdx，得 I=eˣcos x+∫eˣsin x dx。
  2. 令 J=∫eˣsin x dx，分部得 J=eˣsin x−I。
  3. 代回 I=eˣcos x+eˣsin x−I，所以 2I=eˣ(cos x+sin x)。
  4. 因此 I=(1/2)eˣ(cos x+sin x)+C；微分後 sin 項抵消，得到 eˣcos x。

換你一步 · 先自己想

若多項式 x³ 每次都放在 u，連續分部後它會依序變成什麼？

依序微成 3x²、6x、6、0；這種逐步降次讓積分能結束。

容易卡住：循環積分回到原式時，原 I 的正負號決定如何移項；不能把它直接刪掉。

對 ∫sinᵐx cosⁿx dx，若 sin 的冪是奇數，可留 sin x dx，剩下偶次 sin 用 1−cos²x 代換，然後令 u=cos x。若 cos 是奇次，則反過來留 cos x dx、令 u=sin x。

先做除法，讓剩下的分式是真分式

部分分式分解先要求分子次數低於分母。若不低，就先作多項式除法，寫成多項式加上一個餘式分式。這一步常直接把積分變成冪次與對數，不必設許多未知係數。

分解是在原式的合法定義域上成立；被分母排除的點不會因改寫消失。算好後可通分回去核對分子，避免除法餘項符號錯誤。

本課示範 · 自編

計算 ∫x²/(x−2)dx。

  1. 多項式除法給 x²=(x−2)(x+2)+4。
  2. 因此 x²/(x−2)=x+2+4/(x−2)，要求 x≠2。
  3. 逐項積分得 x²/2+2x+4ln|x−2|+C。
  4. 把分解式通分回去可得到 x²；再微分答案能作第二次檢查。

換你一步 · 先自己想

分子三次、分母二次時，應先分解係數還是先作除法？

容易卡住：餘式可能是常數或低次多項式；不能把它省略，只保留除出來的多項式。

第 18 課 / 小節 02

相異一次因式：每個因式給一個常數分子

若分母為相異的一次因式 (x−a)(x−b)，可寫 A/(x−a)+B/(x−b)。通分後兩邊的分子應恆等，因此可代入方便的 x 或比較各次係數求 A、B。

代入分母零點是在「清掉分母後的多項式恆等式」中進行，不是把原分式帶到未定義處。每項積成 ln|x−a| 時，注意線性因式是否還有額外係數。

本課示範 · 自編

計算 ∫3/[x(x+1)]dx。

  1. 先設 3/[x(x+1)]=A/x+B/(x+1)。
  2. 清分母得 3=A(x+1)+Bx；代 x=0 得 A=3，再比 x 係數得 B=−3。
  3. 積分變成 3∫dx/x−3∫dx/(x+1)。
  4. 答案為 3ln|x|−3ln|x+1|+C，限不跨越 −1、0 的合法區間。

換你一步 · 先自己想

若清分母後得到 2=A(x−1)+B(x+2)，代 x=1 能先找哪個係數？

A 那項消失，得到 2=3B，因此 B=2/3。

容易卡住：係數可能為負；不要因原分子為正，就假定每一個分式係數都正。

第 18 課 / 小節 03

重複根與二次因式要把所有項列齊

分母有 (x−a)ᵏ 時，要列 A₁/(x−a)+A₂/(x−a)²+…+Aₖ/(x−a)ᵏ，不能只列最高次。對實數範圍不可約二次式 q(x)，分子要用一次式 Ax+B；若 q 重複，也要逐次列到其冪次。

這些分子的次數必須低於相應因式。積分二次因式時，可把分子拆成分母導數的倍數加常數：前者給 ln，後者常給 arctan。

本課示範 · 自編

  2. 第二個積分拆成 ∫2x/(x²+4)dx+∫dx/(x²+4)。
  3. 第一項以 u=x²+4 得 ln(x²+4)；第二項用 arctan 的反鏈鎖律得 (1/2)arctan(x/2)。
  4. 總結果為 ln(x²+4)+(1/2)arctan(x/2)+C；x²+4 永遠為正，這個 ln 不需額外絕對值。

無窮區間不是把 ∞ 當成普通數字代入

∫ₐ^∞f(x)dx 定義為 limᵦ→∞∫ₐᵇf(x)dx。先對有限 b 做一般定積分，再看 b 的極限；只有極限是有限實數才稱收斂，並以它作積分值。若極限無界或不存在，就發散。

p 型給重要尺度：∫₁^∞x⁻ᵖdx 在 p>1 時收斂，p≤1 時發散。p=1 要用 ln b；其他 p 可用 b^(1−p) 判斷，不能除以剛好為零的 1−p。

本課示範 · 自編

判斷 ∫₂^∞x⁻²dx，並比較 ∫₁^∞dx/x。

  1. 第一題改寫成 limᵦ→∞∫₂ᵇx⁻²dx。
  2. 有限積分為 [−1/x]₂ᵇ=1/2−1/b，極限為 1/2，故收斂。
  3. 第二題有限積分為 [ln x]₁ᵇ=ln b，當 b→∞ 無界，所以發散。
  4. 兩個被積函數都趨近 0，但只有第一個衰減得足夠快；趨近 0 不保證累積量有限。

換你一步 · 先自己想

∫₁^∞x^(−3/2)dx 由 p 型判別應收斂還是發散？

p=3/2>1，所以收斂；若要求值，還要寫極限並計算，得到 2。

容易卡住：沒有「把 ln∞ 算成某個實數」這種操作；要寫 ln b 的極限為無界。

有限端點的無界高度也要改成單側極限

若 f 在下端 a 無界，定義 ∫ₐᵇf=limₜ→ₐ⁺∫ₜᵇf；在上端 b 無界則由內部 t→b⁻。函數高度無限大，不一定使總累積發散，取決於它在端點附近的成長速度。

在 0 附近，∫₀¹x⁻ᵖdx 的門檻與無窮遠相反：p<1 收斂、p≥1 發散。若根式在端點消失，可先找合法區間內的反導數，再以單側極限評估端點。

本課示範 · 自編

判斷 ∫₀⁴dx/√x，並說明為什麼高度無界仍可能收斂。

  1. x=0 是奇點，先寫 limₜ→₀⁺∫ₜ⁴x^(−1/2)dx。
  2. 有限積分為 [2√x]ₜ⁴=4−2√t。
  3. t→0⁺ 時得到有限值 4，所以收斂；這裡 p=1/2<1。
  4. 若改成 1/x，就會得到 ln4−ln t，t→0⁺ 時無界，因此發散。

換你一步 · 先自己想

遇到 ∫₀¹1/√(1−x²)dx，應先檢查哪個端點？

x=1 的分母為 0，應把上限換成 b<1，先積分再取 b→1⁻ 的極限；反導數可由 arcsin 的導數核對。

容易卡住：兩種 p 型不要混用：無窮遠要求 p>1，靠近 0 則要求 p<1。

第 19 課 / 小節 03

內部奇點與兩端無窮，必須各自收斂

若區間內 c 是奇點，就拆成 ∫ₐᶜ與∫ᶜᵇ，分別取 c⁻、c⁺ 的極限。只有兩邊都有限才可相加。整條實數線也要在某個有限點拆成左右兩邊，各自判斷。

把兩個相反的發散量綁成同一個對稱極限，可能得到柯西主值，卻不等於通常定義的瑕積分。先確認存在，才能做加減運算。

本課示範 · 自編

判斷 ∫₋₁¹dx/x，為何不能直接利用奇函數說答案為 0？

  1. x=0 是內部奇點，需分成從 −1 到 0、從 0 到 1。
  2. 左側有限截斷積分為 ln|t|，t→0⁻ 時趨向 −∞。
  3. 右側有限截斷積分為 −ln s，s→0⁺ 時趨向 +∞；兩側都不收斂。
  4. 因此通常瑕積分發散。對稱截斷雖可得到 0 的主值，但不能代替兩個獨立極限。

換你一步 · 先自己想

一邊的瑕積分收斂，另一邊發散，整題可否仍稱收斂？

不可以。每一個獨立奇點、每一端的瑕積分都要收斂，才能相加。

容易卡住：−∞+∞ 不是 0；對發散量使用奇偶相消，會跳過積分存在性的檢查。

第 19 課 / 小節 04

比較判別：用已知尺度夾住未知累積

對尾部或奇點附近的非負函數，若 0≤f≤g 而 ∫g 收斂，則 ∫f 也收斂；若 0≤g≤f 而 ∫g 發散，則 ∫f 也發散。較大者有限能保證較小者有限，較小者無限能保證較大者無限。

若 f/g 趨近正的有限常數，兩者同收斂或同發散。比較只需在出問題的端點附近成立；正常的有限區段不決定尾部的發散性。若函數有正負，須另處理，例如先檢查絕對收斂，不能直接套非負比較。

本課示範 · 自編

不用求反導數，判斷 ∫₁^∞dx/(x²+4) 是否收斂。

  1. 對 x≥1，0≤1/(x²+4)≤1/x²。
  2. ∫₁^∞1/x²dx 是 p=2 的收斂積分。
  3. 由比較判別，原積分也收斂；這一步只回答存在性，沒有給出它的精確值。
  4. 若某函數只被 1/x 這個發散函數壓在下面，則還不能判斷，因上界太寬鬆。

換你一步 · 先自己想

已知 0≤f(x)≤1/x 且 x≥1，是否就能斷言 ∫f 發散？

不能。被發散的大函數蓋住沒有結論，例如 1/x² 也在它下面卻收斂。

容易卡住：比較的方向決定結論；寫出不等式與已知 p 型後，才知道能否使用。

基礎 A / 需要時查閱

負數、括號與運算順序

這課學會：辨認正負號，算出含括號與次方的式子。

先想成數線上的位置

0 右邊是正數，左邊是負數。3 + (−5) 可以想成先站在 3，再往左走 5 步，最後在 −2。減去一個負數等於加上它的相反數：3 − (−5) = 3 + 5 = 8。

乘除看負號個數：兩個負數相乘是正數；一正一負相乘是負數。除法遵循相同符號規則，但分母不能是 0。

因為 3 + (−3) = 0，所以 (−2) × [3 + (−3)] 也等於 0。分配乘法後，得到 −6 + (−2) × (−3) = 0；後面那項必須是 6，才能和 −6 抵消。

(−2) × (−3) = 6
(−6) ÷ 2 = −3
2³ = 2 × 2 × 2 = 8

示範：3 + 2 × (−4)²

  1. 先處理括號內的數，再算次方：(−4)² = (−4) × (−4) = 16。
  2. 接著乘法：2 × 16 = 32。
  3. 最後加法：3 + 32 = 35。
括號很重要：(−3)² = 9，但 −3² 表示 −(3²)，所以是 −9。

微積分常要把數字代進含 x² 的式子。若代入負數卻漏掉括號，後面的極限與導數就會算錯。

記住：先括號、再次方、再乘除、最後加減；同一層由左到右算。
基礎 B / 需要時查閱

分數：先知道「一份」有多大

這課學會：通分、乘除與合法約分。

1/3 是把一個整體分成 3 等份，取其中 1 份。分母決定每份大小，分子決定拿幾份。所以 1/2 + 1/3 不能直接把分子、分母分別相加。

示範：1/2 + 1/3

  1. 把兩種份量改成共同的「六分之一」。
  2. 1/2 = 3/6，1/3 = 2/6；分子、分母同乘一個非零數，數值不變。
  3. 現在單位相同，可以加分子：3/6 + 2/6 = 5/6。
23 × 34 = 612 = 1/2
23 ÷ 45 = 23 × 54 = 5/6

除以非零分數等於乘它的倒數。上面的除法也可以反向檢查：(5/6) × (4/5) = 2/3。約分是把分子與分母一起除以相同的非零因數，例如 6/12 同除以 6 得 1/2。

只能約共同因數：(2x)/(2y) 可約掉 2（y ≠ 0）；(x + 2)/x 不能把加號旁的 x 刪掉。正確拆法是 1 + 2/x（x ≠ 0）。
記住：加減先通分；約分先確認是乘在一起的因數。
基礎 C / 需要時查閱

x 是一個可以代入的數

這課學會：解簡單方程，展開括號，把式子拆成乘積。

2x 表示 2 × x。式子 2x + 3 的數值取決於 x；方程 2x + 3 = 11 則問「哪個 x 能讓左右相等？」

示範：解 2x + 3 = 11

  1. 左右都減去 3：2x = 8。等式像天平，兩邊做一樣的事。
  2. 左右都除以 2：x = 4。
  3. 代回檢查：2 × 4 + 3 = 11，成立。

展開與因式分解互為相反方向

a(b + c) = ab + ac
(x + 2)² = (x + 2)(x + 2) = x² + 4x + 4
x² − a² = (x − a)(x + a)

展開把乘積變成相加；因式分解把相加變回乘積。例如 x² − 4 = x² − 2² = (x − 2)(x + 2)。這會在極限題中幫你找出共同因數。

(x + 2)² 不是 x² + 4，因為還有兩個交叉乘積 2x + 2x。也不能在等式兩側除以可能等於 0 的式子卻不討論條件。
記住：遇到「平方減平方」，先找 (前者 − 後者)(前者 + 後者)。
